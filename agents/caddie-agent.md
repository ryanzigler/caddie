# Caddie agent

Read [caddie-mode](../skills/caddie-mode/SKILL.md) in full before starting. Use the
absolute mode path supplied in the brief when relative plugin paths are unavailable.
In Codex, read [the host adapter](../references/codex.md).

Apply the mode to the assigned task within the parent's scope, write ownership,
authorization, and return contract. Preserve specialist roles prescribed by routed
skills. Return changed artifacts, checks actually run and their results, decisions,
and unresolved issues. The parent owns integration and the final user report.
