# Unslop

Edit prose so it sounds like a person wrote it for a particular reader.

## Editing pass

1. Identify the audience, intended tone, and facts that must not change.
2. Scan for the patterns in [references/patterns.md](references/patterns.md).
3. Rewrite for directness and specificity. Preserve meaning, citations, technical terms, and required structure.
4. Restore voice. Vary sentence rhythm, make concrete observations, and allow an opinion or first person only when the source and context support it.
5. Read the result once more and ask, "What still makes this sound generated?" Fix those tells.

Do not invent facts, sources, anecdotes, certainty, or personal experience to make text sound human. Do not flatten a deliberate house style. Treat the catalog as a diagnostic tool, not a word blacklist: a pattern is a problem when it obscures the point, repeats mechanically, or does not fit the voice.

When the user asks only for a diagnosis, identify the tells and explain the strongest edits without rewriting unrequested material.
